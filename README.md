Power BI Sales Dashboard

## Overview

This project is an interactive Power BI dashboard used to analyze sales and profit performance across different regions, segments, and time periods.

## Key Metrics

* Total Sales: 2.27M
* Total Profit: 315.51K
* Total Quantity: 40K
* Total Discount: 1.55K

## Features

* Monthly profit trend analysis
* Region-wise sales comparison
* Segment-wise profit distribution
* Top customer insights
* Quarter filter for dynamic analysis


## Tools Used

* Power BI
* Excel

## Insights

* West region performs best in sales
* Consumer segment generates highest profit
* Sales peak towards year-end
